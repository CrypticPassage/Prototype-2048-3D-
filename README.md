# Prototype 2048 3D
Прототип гри 2048 3D.

Відеодемонстрація прототипу: https://youtube.com/shorts/vG_6esgUE1g

Версія Unity: 6000.0.52.f1.

Прототип розроблено з допомогою Zenject.

Керування: натисність в любому місці екрану та ведіть пальцем вліво-вправо для зміни позиціїї куба, який будете кидати. Щоб кинути куб, необхідно відпустити палець у нижній частині екрану.

Кінець гри наступає, коли ви отримаєте куб зі значенням 2048. В інших випадках при невдалих спробах Ви можете натиснути кнопку "Replay" у правій верхній частині екрану.

Над скриптами Контроллеру, Сервісів та Баз Даних Ви можете знайти короткі summary-коментарі щодо того, що дані скрипти роблять та за що відповідають.

Велике дякую за увагу!
